## 3. 성능 측정 (P-8, 방법 승인·수치 미확정)

배포 빌드를 `/rps-lab/` 아래 정적 서버로 서빙하고 Chrome headless에서 측정했다. 시드는 앱 코드가 아니라 스크립트가 `battles`/`meta.stats`를 일괄 기록했고(1,000/10,000/100,000건), 100,000건은 화면에 "100000회"·20행·"1 / 5000"이 표시됨을 확인했다. 지표별 5회(자동 애니메이션은 3회) 중앙값/최댓값(ms).

### ① ② 기록 페이지

| 저장 규모 | 직접 로드(JS 포함) → 통계·첫 20건 | 게임→기록 클라이언트 이동 | "다음" 클릭 → 갱신 |
|---|---|---|---|
| 1,000건 | 43 / 46 | 34 / 41 | 3 / 7 |
| 10,000건 | 44 / 48 | 33 / 43 | 3 / 4 |
| 100,000건 | 80 / 88 | 30 / 39 | 3 / 6 |

100,000건의 직접 로드는 1,000건의 약 1.9배이고, 클라이언트 이동과 페이지 이동은 규모와 무관했다(키셋 페이지네이션).

### ③ ④ ⑤ 자동 대결 (저장 1,000건 기준)

| 지표 | CPU 1배 | CPU 4배(CDP 스로틀) |
|---|---|---|
| 즉시 100회 완료 | 65 / 71 | 23 / 31 |
| 즉시 1,000회 완료 | 49 / 172 | 59 / 78 |
| 즉시 1,000회 완료(100,000건 DB) | 48 / 49 | — |
| 애니메이션 1,000회 완료 | 7,308 / 7,358 | 7,159 / 7,163 |
| 50ms 초과 긴 작업 횟수(즉시 100·1,000, 애니메이션 1,000) | 0 / 0 | 0 / 0 |
| 최대 긴 작업 길이 | 0 | 0 |
| 중지 클릭 → 요약 표시 | 3 / 3 | 5 / 14 |
| 중지 후 기록 증가 | 0 / 0 | 0 / 0 |

**해석과 한계**
- 위 수치는 Apple Silicon 데스크톱의 headless Chrome에서 나온 값이다. CDP CPU 스로틀 4배의 즉시 100회 값이 1배보다 작은 것은 측정 잡음(JIT·캐시)이며 스로틀 효과가 이 규모에서는 관찰되지 않았다는 뜻이다. **실제 모바일 기기 확인은 하지 못했다(미검증).**
- 긴 작업 0회·최대 0ms는 `PerformanceObserver('longtask')`가 기록한 결과다. 이 관측이 headless에서 모든 작업을 잡는다는 별도 검증은 하지 않았다.
- 애니메이션 1,000회가 약 7.3초인 것은 설계(묶음 10건 × 70ms 틱 100회)대로이며 성능 문제가 아니다.
- SC2-001·003·004·007의 **목표 수치는 이 값을 근거로 사용자와 합의해야 한다.** 이 문서는 목표 달성 여부를 판정하지 않는다. 상대 기준(100,000건 첫 화면이 1,000건의 몇 배 이내인가, 긴 작업 50ms 초과 0회)은 위 표에서 각각 약 1.9배, 0회였다.

## 5. 최종 UI 레퍼런스와 실제 화면의 비교

`docs/references/rps-lab-v2-ui.html`을 같은 상태(직접·자동·기록, 폭 820·390)로 캡처해 나란히 비교했다.

- **일치**: 색 토큰, 승/패/무 색상 카드, 모드 토글, 대결 영역(나|VS+결과|컴퓨터), 선택 버튼(데스크톱 흰 배경+테두리, 모바일 연한 채움), 통계 요약·막대·범례, 기록 표/카드, 페이지 이동, 헤더·탐색 위치(데스크톱 오른쪽, 모바일 제목 아래).
- **발견해 수정한 차이**: 처음 구현에서는 앱 루트 안쪽 여백이 없어 카드 폭이 820px로 레퍼런스(772px, 390px 화면 366px)와 달랐고 헤더가 가장자리에 붙었다. 레퍼런스의 `.frame`/`.app` 구조(안쪽 여백 24px, 컨테이너 600px 이하 12px)로 맞춰 **카드 폭 772px(≥820px), 366px(390px 화면)** 을 측정으로 확인했다.
- **남은 차이(의도된 것)**: 레퍼런스의 미리보기 도구와 요소 주석, 샘플 숫자, "프로토타입 표시용" 안내 문구는 앱에 없다. 최종 HTML의 탐색 버튼은 프로토타입 표현이고 앱은 `next/link` 링크다(UC 1절). 저장 안내 박스 등 상태 화면은 레퍼런스와 나란히 캡처하지 않았고 문구·구조는 컴포넌트 테스트로 검증했다(시각 비교는 미수행).
